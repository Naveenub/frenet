# Roadmap
- [x] Phase 1: identity, discovery, encrypted messaging, direct connections, monitoring dashboard
- [x] Phase 2: content-addressed encrypted storage + replication, DHT records, peer-hosted content, DIDs (`did:key`, and rotatable `did:frenet` with a pre-committed next key), verifiable credentials (VC-JWT, presentations, issuer revocation distributed by push + DHT pull), account recovery (full encrypted archive, key backup, Shamir shares, key rotation), dashboard identity and credentials view. Open: independent review of the Shamir code and the key-log design, name continuity across a rotation, a revocation transparency log / status lists, other DID methods, automatic re-announcement of restored blocks
- [ ] Phase 3: decentralized browser (gateway, signed updatable names and keyword search done; human-memorable global names, full-text search, dApps open); voice/video (WebRTC signalling + dashboard calls done, no TURN/relayed media, no group calls); communities and group chat (done: owner-managed rosters, signed events; open: history sync, relaying, store-and-forward); node operator tools (done: bans, disconnect, sweep, stats; open: remote administration); governance (done: advisory signed ballots; open: enforcement, delegated or weighted voting)
- [ ] Phase 4: independent audits, scalability tests, cross-platform apps, public testnet
